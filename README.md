# Atlas GitHub Pages sitesi

Bu klasör doğrudan GitHub Pages üzerinde yayınlanabilecek statik Atlas sitesidir.

## İçerik

- Ana sayfa: `/`
- Gizlilik politikası: `/privacy/`
- Kullanım koşulları: `/terms/`
- Destek: `/support/`

## Yayınlama

1. GitHub'da `atlasfinansapp` adında herkese açık bir depo oluşturun.
2. Bu klasörün içindeki dosya ve klasörlerin tamamını deponun köküne yükleyin.
3. Depoda **Settings → Pages** bölümünü açın.
4. **Build and deployment** altında **Source: Deploy from a branch** seçin.
5. **Branch: main**, klasör olarak **/(root)** seçip **Save** düğmesine basın.
6. Birkaç dakika sonra sayfa `https://bataman06.github.io/atlasfinansapp/` adresinde açılır.

App Store Connect alanları:

- Support URL: `https://bataman06.github.io/atlasfinansapp/support/`
- Terms of Use URL: `https://bataman06.github.io/atlasfinansapp/terms/`
